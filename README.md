## Usage

### HTML Templates
Open the `.html` file in any browser, edit the content directly in the HTML, then print to PDF (Ctrl+P / Cmd+P → Save as PDF).

### Markdown Template
Render on GitHub, in any Markdown editor, or convert to PDF using `pandoc`:
```bash
pandoc minimal.md -o cv.pdf
```

### JSON Template
Matches the [Jobsnowonline](https://www.jobsnowonline.com) CV data schema. Import directly into the [online CV builder](https://www.jobsnowonline.com) or use programmatically.

### LaTeX Template
Compile with any LaTeX distribution:
```bash
pdflatex academic.tex
```

### Plain Text
Copy-paste into email, online application forms, or ATS systems.

## CV Tips

1. **Keep it to 1-2 pages** — recruiters spend 6 seconds on average scanning a CV
2. **Use action verbs** — "Led", "Built", "Improved", "Achieved"
3. **Quantify results** — "Increased sales by 30%", "Managed a team of 12"
4. **Tailor to the job** — match keywords from the job description
5. **Include a summary** — 2-3 lines at the top highlighting your value
6. **List relevant skills** — include both technical and soft skills
7. **Proofread** — typos are the #1 reason CVs get rejected
